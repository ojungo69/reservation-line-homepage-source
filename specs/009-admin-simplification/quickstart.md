# Quickstart: 管理画面の整理を確かめる

画面ごとの約束は [contracts/ui-fields.md](./contracts/ui-fields.md) にある。ここでは、その約束を手元と確認用環境で確かめる順番だけを書く。

## 1. 自動の試験

CI と同じ一式を、リポジトリの直下で通す。

```sh
npm run cf:types
npm run typecheck
npm run knip
npm run test:unit -- --coverage
npm run test:worker
node --test .github/scripts/*.test.mjs
npm run admin:typecheck
npm run admin:build
npm run coverage:admin
npm run cf:check
npm run audit:root
npm run audit:admin
```

期待する結果: すべて成功する。

この整理で足した試験は、次のどの場面でも、送る内容が今と同じ形になることを確かめる。

- 枠が 0 件・1 つ・2 つ以上の店舗
- 設定の読み込み中・最初の取得の失敗・前の設定が残る取り直しの失敗
- 店舗の切り替え
- 前の予約から次の予約を作るときに、停止中の枠を引き継いだ場合

## 2. 手元の画面で確かめる

手元の `wrangler dev` で認証なしに使える管理 API は `/api/admin/me` だけ（[docs/INSTALL.md](../../docs/INSTALL.md) の 1 の終わり）。ほかの管理 API は Access の認証が要るので、手元の画面は、組み立てた管理画面を配り、`/api/**` の応答を見本に差し替えて確かめる（例: Playwright の route）。今の予定表と新しい予定表の両方を見る。新しい予定表は、`/api/admin/me` の応答の `calendarV2` を `true` にすると出る。

各行は、店舗の稼働中の枠が 1 つの状態から始める。枠の数を変えた行の後は、枠 1 つに戻してから次の行に進む（予約の詳細などは枠 1 つが前提）。

| 確かめること | 手順 | 期待する結果 |
| --- | --- | --- |
| 手動予約（枠 1 つ） | 予定表の空き枠から作成画面を開き、メニュー・日時・お客様だけを入れて保存する | リソースの欄と「担当」が出ない。店舗の欄は、選べる店舗が 1 つのアカウント（店舗スタッフ）では出ない。予約経路は「店頭」。その店舗の枠に保存される |
| 手動予約（枠 2 つ） | 店舗の稼働中の枠を 2 つにしてから作成画面を開く | リソースの欄が出て、選ぶまで保存できない。確認の画面に「担当」が出る |
| 手動予約（枠 0） | 店舗の稼働中の枠を 0 にしてから作成画面を開く | 未設定の案内が出て、保存できない |
| 予約の詳細 | 作った予約を開く | リソースの行と「来店履歴」が出ない。ボタンは「開始時刻を変更」「長さを変更」 |
| 開始時刻・長さの変更 | それぞれの画面を開く | 題名と送信ボタンが新しい名前。説明文にリソース名が無い |
| ブロック・繰り返しブロック | 予定表のブロック作成（今の予定表から開く。新しい予定表には単発のブロックを作る入口が無い）と、店舗設定の繰り返しブロックを開く | 枠が 1 つならリソースの欄が出ない |
| 休業日 | 休業日の追加で開始日だけを選ぶ | 終了日に同じ日付が入り、保存できる |
| 予約管理 | 店舗を選んで開き、全店舗に切り替える | 店舗を選んでいる間は店舗の列が無い。全店舗で出る。「来店中」と CSV のボタンが無い |
| LINE 友だち | 一覧と紐付けを開く | 切り替えと「紐付け先の店舗」が無い |
| 顧客カルテ | アレルギーの記録があるお客様を開く | アレルギーは「注意事項」にだけ出る |
| リソース一覧 | 店舗設定のリソースのタブを開く | 「削除」が無く、「無効化」「有効化」が使える |


## 3. 確認用環境で確かめる（本番に出す前）

オーナーが確認用環境で、ユーザーストーリー 1〜5 の受け入れの場面を見る。

- 新しい予定表の切り替えがオンなら、予定表の空き枠から作成画面を開いて予約を作り、その詳細を開く（spec の US1-8）。
- 枠が 0 件と 2 つ以上の場面は、確認用環境のデータでは起きない。1 の自動の試験と 2 の手元の確認で確かめる。
- 試しの予約を作る前に、確認用環境でその操作が外部に通知や同期を送らないことを確かめる。

## 4. 本番に出した後

- 本番の管理画面で手動予約の作成画面を開き、リソースの欄が出ないこと、予約経路が「店頭」であることを見る。店舗の欄が出ないことは、選べる店舗が 1 つのアカウント（店舗スタッフ）で見る（店舗を 2 つ以上扱うオーナーには出る）。
- スタッフに配っている操作の説明資料を、新しい操作の名前に合わせる（運用側の作業）。
